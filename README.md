# trust&Co Web Services — 4D-style website

A premium interactive single-page website with:
- 3D particle field powered by Three.js
- interactive cursor/magnetic interactions on desktop
- animated sections and scroll reveal
- responsive mobile navigation
- services, portfolio, process, statement and contact sections
- GitHub Pages compatible static files

Upload `index.html`, `style.css`, and `script.js` to the root of a public GitHub repository.
The Three.js library is loaded from jsDelivr, so an internet connection is required for the 3D hero effect.
The contact form is front-end only until connected to an email/form backend.
